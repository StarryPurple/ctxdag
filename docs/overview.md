# 第 1 部分：总览与术语

## 1. 问题与目标

多个 AI Agent（由 AI 模型驱动、独立执行子任务的程序单元）协作时，最常用的做法是
"把全部上下文贴给每个 Agent"。这样有三个问题：

- **贵且慢**：上下文越长，token 费用和延迟越高；
- **稀释注意力**：大部分资料与当前子任务无关，模型容易抓错重点；
- **依赖不可见**：没有记录"这个结果依赖了哪些材料"，出错时说不清环节。

目标：让"谁需要谁的什么结果"变得**显式、可验证**，并且每个 Agent 只看到自己
需要的那部分上下文。实现方式是两条：

- **内容寻址**：内容相同的节点有相同的 id，天然去重、天然不可变；
- **按需展开**：Agent 声明依赖后，运行时只把依赖集（见术语表）展开成它的上下文。

示例（对照）：

```python
# 没有 ContextDAG：每个 Agent 都收到全部历史
worker1 的上下文 = 全部对话历史
worker2 的上下文 = 全部对话历史

# 有 ContextDAG：每个 Agent 只看到自己的依赖集
worker1 的上下文 = expand(brief)
worker2 的上下文 = expand(node1)   # 自动包含 brief，但不包含无关内容
```

## 2. 范围

本书按阶段分部分，每部分一个文件。当前部分：

- **第 1 部分（本文件）**：总览与术语——全书共用；
- **第 2 部分（`protocol.md`）**：协议设计——节点、标签、展开与会话、约束。

未来的部分（到阶段再单开文件）：测量层、引擎层、训练线。

本卷只覆盖**纯 API 模型可用的文字层协议**：不依赖任何推理引擎的内部，任何通过
接口调用的模型都能使用。明确不在本卷范围：引擎内部优化（如按节点 id 管理缓存）、
模型训练线、非 API 模型（本地权重）专属能力。人类可读的展示（对话审查、节点
超链接）由展示层实现，不在本卷；协议保证给定 id 一定能解析到全文与摘要。

## 3. 术语表

规则：全书共用；每个词一句话定义；新增术语必须在此登记后才能在其他部分使用。

- **Agent（智能体）**：由 AI 模型驱动、独立执行一个子任务的程序单元。
- **节点（Node）**：一块自包含的内容，如一个子任务的结果、一段思考、一次工具输出；是上下文的基本单元。
- **内容寻址（content addressing）**：用内容的指纹（哈希）作为节点的 id；内容相同则 id 必相同。
- **指纹（fingerprint）**：把内容经 SHA-256 计算得到的定长字符串，这里取前 16 位十六进制。
- **直接依赖（direct dependency）**：节点声明"我需要读哪些其他节点"的引用关系；`refs` 中列出的是直接依赖。
- **DAG（有向无环图）**：只能向前、不形成环的依赖图；保证不存在 A 依赖 B 而 B 又依赖 A。
- **依赖集（dependency set）**：从某节点出发，沿依赖边能到达的全部节点集合（含它自己），即直接依赖与全部间接依赖的综合。
- **展开（expand）**：把依赖集按确定顺序渲染成文字，作为模型看到的上下文。
- **上下文（context）**：模型在生成时所看到的全部文字。
- **前瞻声明（ref）**：生成前声明"我要读哪些节点的依赖集"的标签 `<ref=...>`。
- **缺页请求（require）**：生成中途发现缺少节点时发出的补入请求，标签为 `<require=...>`。
- **契约（contract）**：运行时强制执行的规则集合；违反即拒绝，而不是静默接受。
- **Grounding 约束**：要求引用必须出现在当前上下文可见节点表中的规则。
- **稳定序列化**：同一节点在包含它的任何依赖集中渲染出的字节完全一致。
- **规范拓扑序**：依赖集展开的一种确定顺序（依赖在前，同层按 id 排序）。
- **编排层（orchestrator）**：负责拆解任务、决定节点边界与依赖的框架代码。
- **API 模型**：只通过接口调用、无法访问其内部状态的模型（如各家云端模型）。
- **目录（catalog）**：展开上下文中列出的可申请节点清单，每条 = id + 摘要。
- **可申请范围**：编排层指定的、本次展开允许缺页请求的节点集合。
- **摘要（summary）**：节点的短描述，用于目录提示与交接；可来自启发式提取、显式 `<summary>` 或读者摘要节点。
- **页面缺失（page fault）类比**：程序访问了不在内存里的数据，需要从慢速存储调入；这里指生成中途发现缺少节点，发出缺页请求，运行时扩展依赖集并重新展开。
